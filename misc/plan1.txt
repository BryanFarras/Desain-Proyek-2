1. Jembatan Komunikasi (ROS 2 to Web Bridge)
Secara bawaan, ROS 2 berkomunikasi menggunakan protokol DDS (Data Distribution Service) yang tidak dapat dibaca langsung oleh peramban web (browser)1. Oleh karena itu, Anda memerlukan jembatan (bridge):

rosbridge_suite (WebSockets): Ini adalah metode paling standar di ekosistem ROS. Node rosbridge_server akan dijalankan di Raspberry Pi 4B Anda untuk mengubah topik, layanan, dan aksi ROS 2 menjadi API JSON berbasis WebSocket yang dapat diakses langsung oleh browser.
MQTT (Message Queuing Telemetry Transport): Sesuai dengan rancangan teknis awal proposal Anda1, Anda bisa menggunakan MQTT (misalnya dengan broker Eclipse Mosquitto)1. Anda perlu menulis node ROS 2 sederhana di Pi 4B yang berfungsi menjembatani topik ROS 2 (seperti status baterai atau posisi) ke broker MQTT, yang kemudian akan di-subscribe oleh aplikasi web1.

2. Stack Perangkat Lunak (Software Stack)
Frontend (Antarmuka Web):
Framework: Anda dapat menggunakan framework modern seperti React.js, Vue.js, atau Next.js untuk membangun komponen dashboard yang reaktif2.
roslibjs: Pustaka JavaScript wajib jika Anda menggunakan rosbridge. Pustaka ini memungkinkan web dashboard Anda melakukan subscribe topik ROS (seperti koordinat posisi), publish (seperti mengirim perintah gerak), dan memanggil ROS services.
ros2djs / Canvas HTML5: Digunakan untuk memvisualisasikan peta occupancy grid 2D hasil dari SLAM Toolbox langsung di halaman web Anda1.
Backend (Opsional, untuk penyimpanan data):
Jika Anda memerlukan fitur penyimpanan riwayat evakuasi, log sensor, atau manajemen pengguna, Anda dapat menggunakan backend ringan seperti Node.js (Express) atau Python (FastAPI)2.
3. Data Utama yang Harus Dimonitor
Web monitoring Anda harus dirancang untuk menerima dan menampilkan visualisasi data berikut secara real-time dari rover:

Status & Mode Operasi: Menampilkan apakah robot sedang dalam mode Standby atau Mode Evakuasi Aktif1.
Lokalisasi Spasial (Posisi Robot): Koordinat $(x, y)$ dan orientasi robot terhadap peta dari topik /pose atau transformasi tf1.
Status Baterai & Daya: Tegangan operasional dan sisa kapasitas baterai untuk menjamin ketahanan operasi1.
Peta Lingkungan & Jalur Navigasi: Menampilkan peta grid yang diperbarui oleh SLAM Toolbox serta jalur alternatif (path planning) yang direncanakan oleh Nav21.
Umpan Video (Video Stream): Jika Anda menggunakan kamera, Anda memerlukan paket seperti web_video_server di ROS untuk mengalirkan umpan gambar kamera (raw image) ke elemen image HTML di web.

4. Infrastruktur Jaringan
Wi-Fi Lokal: Seluruh sistem (Raspberry Pi 4B di rover dan perangkat monitor/laptop operator) harus terhubung dalam jaringan Wi-Fi lokal yang sama1. IP Master (Raspberry Pi) dan IP perangkat monitor harus dikonfigurasi dengan benar agar komunikasi data berlatensi rendah dapat tercapai demi kelancaran pengiriman telemetri dan mekanisme Human in the Loop (HITL)1.
